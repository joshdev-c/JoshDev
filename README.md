PERSONAL PORTFOLIO USING NEXTJS

A professional, responsive, and interactive portfolio website built with Next.js, Tailwind CSS, and Framer Motion. This project showcases a clean design with a custom color palette, smooth animations, and a seamless dark/light mode experience.

Features
-> Clean hero section with typing animation
-> Project showcase with interactive design
-> About section with skills and experience
-> Responsive navbar (shows/hides on scroll)
-> Dark and light mode support

Tech Stack
-> Next.js
-> Tailwind CSS
-> Framer Motion
-> Lucide React
-> Next Themes
-> React Type Animation
